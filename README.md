# NoteNest: A Collaborative Student Knowledge-Sharing Platform

## Project Description

NoteNest is a collaborative student knowledge-sharing platform designed to allow students to upload, share, and access academic resources. Uploaded resources are reviewed by an administrator before they become available to other students.

## Features

- Student Registration
- Student Login
- Admin Login
- Student Dashboard
- Upload Academic Resources
- Resource Approval and Rejection
- Browse Approved Resources
- Download Resources
- Student Profile
- Comments
- Ratings
- Favorites
- Category and Subject Management

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
- phpMyAdmin
- Visual Studio Code
